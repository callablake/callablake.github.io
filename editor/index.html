How do I get a token?
  1. Sign in to GitHub with the account that owns the site's repository.
  2. Open github.com/settings/personal-access-tokens/new.
  3. Name it something like "Artwork editor" and pick an expiration (up to a year; you'll need to make a new one when it expires).
  4. Under Repository access, choose Only select repositories and pick the site's repository.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it, and paste it above.

If you're a collaborator on someone else's repository (not the owner), fine-grained tokens won't work there. Create a classic token instead at github.com/settings/tokens/new with the public_repo scope.
